Blocked until owner prompt (`T0 yes` | `merge` | `lock` | `skip`):

- force push
- create repository
- create or delete a Grok Bot
- save a bot routine that mutates
- Drive / bella_rag write
- memory.md write
- send mail
- money / Stripe / DNS / live site
